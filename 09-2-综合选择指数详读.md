## 01 · 原文短摘与要点 / Short excerpt and source summary

> **短摘译意：每头配种母牛的净利润。**  
> **Short excerpt: “net profit per cow mated”.**

这句话位于 PDF 第 1 页的 Interpreting Selection Indexes 部分。  
This wording appears under Interpreting Selection Indexes on PDF page 1.

原文将指数解释为特定生产与市场情景下的利润遗传价值预测。  
The guide interprets an index as predicted genetic merit for profitability in a specified production and market scenario.

它不是当期现金利润，也不是单独一个生长或胴体指标。  
It is not current cash profit or a single growth or carcass measurement.

## 03 · 教学推导：把单位写出来 / Teaching derivation: make the units explicit

下面另建一个假设的两性状指数，所有数字都不是原 PDF 的案例。  
The following hypothetical two-trait index uses original teaching numbers rather than the PDF's example.

假设 ADG 的权重为每 g/day 对应 0.04 分，背膘权重为每 mm 对应 −1.5 分。  
Suppose ADG receives 0.04 points per g/day and backfat receives −1.5 points per mm.

$$
J=0.04\,EBV_{ADG}-1.5\,EBV_{BF}
$$

- 甲的 EBV 为 +35 g/day 与 +0.4 mm，得 **0.8 分**。  
  A has EBVs +35 g/day and +0.4 mm, giving **0.8 points**.

- 乙的 EBV 为 +20 g/day 与 −0.4 mm，得 **1.4 分**。  
  B has EBVs +20 g/day and −0.4 mm, giving **1.4 points**.

乙的增重优势较小，却在这组权重下有更高综合分。  
B has less growth advantage but a higher combined score under these weights.

若只把增重权重改成 0.10，甲得 2.9 分、乙得 2.6 分，排序反转。  
Changing only the growth weight to 0.10 gives A 2.9 and B 2.6 points, reversing the ranking.

排序变化来自目标改变，不意味着原来的 EBV 算错。  
The ranking changes because the objective changed, not because the original EBVs were incorrect.

### 什么条件下才能谈利润 / When can a score be interpreted as profit?

必须先定义货币单位、计价对象、生产周期与成本收益模型。  
First define the currency, accounting unit, production horizon, and cost–return model.

本例没有这些定义，所以指数分不能改名为“元”。  
This example lacks those definitions, so its points cannot be renamed monetary units.

## 04 · 解释“一半”时要确认尺度 / Check the scale before applying one-half

假设另一个教学指数明确采用整体育种值尺度，两头父本分别为 +90 和 +50 个模型货币单位。  
Suppose another teaching index explicitly uses a full breeding-value scale, with sire values +90 and +50 model currency units.

在配偶和评估口径可比等假设下，父本造成的后代组期望差异为 $(90-50)/2=20$。  
With comparable mates and evaluation definitions, the expected progeny-group difference attributable to the sires is $(90-50)/2=20$.

本例进一步假设指数的计价对象是每次配母畜，并使用虚构的模型货币单位。  
This example further assumes a per-mating accounting unit and fictional model currency units.

若每头父本在模型内对应 120 次同等暴露，总期望差额为 $120\times20=2{,}400$。  
If each sire represents 120 equivalent modeled exposures, the expected total difference is $120\times20=2{,}400$.

这不是当前现金收入，也不能在指数已是 EPD 或其他尺度时再机械除以 2。  
This is not current cash income, and an EPD-scale or differently defined index must not be halved mechanically.

## 05 · 像配置文件一样审查指数 / Review an index like a configuration

- 记录 `objective_version`，明确哪一版目标。  
  Record `objective_version` to identify the objective definition.

- 记录每个 `trait_unit` 与 `weight_unit`，避免单位相加错误。  
  Record each `trait_unit` and `weight_unit` to prevent incompatible additions.

- 保留 `evaluation_base` 与 `evaluation_date`，避免跨基准拼分。  
  Keep `evaluation_base` and `evaluation_date` to avoid mixing incompatible scores.

- 将必须过关的条件放入 `eligibility_rules`，不要隐含在总分中。  
  Store non-negotiable requirements in `eligibility_rules` rather than hiding them in the total score.

这些字段是本教程的实现建议，不是 BreedObject 的官方接口或文件格式。  
These fields are original implementation suggestions, not official BreedObject interfaces or file formats.

## 06 · 读到指数 120，我先查四项定义 / Four Definitions I Check When an Index Says 120

看到「指数 120」时，我会先核对育种目标、单位、尺度和版本，再讨论排名或预期价值。  
When I see “index 120,” I check the breeding objective, units, scale, and version before discussing rank or expected value.

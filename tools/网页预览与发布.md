# 网页预览与 GitHub Pages 发布

网页从仓库根目录的 Markdown、`SUMMARY.md` 和正文引用的图片生成。更新书稿后重新构建即可。目录、分篇和详读层级读取 `SUMMARY.md`，发布使用的静态文件由构建生成。

## 本地预览

安装 Python 3 和 Quarto 后，在仓库根目录运行。预览按 Quarto 1.11.9 构建验证。若 Quarto 未加入 `PATH`，可给构建脚本传入 `--quarto` 和可执行文件路径。 [Quarto 安装](https://quarto.org/docs/get-started/)

```sh
python3 tools/build_site.py
```

用命令最后一行打印的站点目录启动浏览器预览。HTTP 模式会加载本地搜索索引。

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory "实际生成的站点目录"
```

浏览器打开 `http://127.0.0.1:8767/` 即可阅读。本地预览和样章构建产物由 Git 忽略。

## 从 `docs/` 发布静态文件

`docs/` 保存分支发布所需的 HTML、搜索索引和站点资源。第一次生成可直接使用新建或空的 `docs/`。后续更新先输出到一个新目录，核对生成结果后把审阅过的静态文件更新到 `docs/`。

```sh
python3 tools/build_site.py --output docs
```

更新下载版时，用 `python3 tools/build_sample.py --full-pdf` 生成全书。检查成品后，复制到 `docs/downloads/breeding-learning-course.pdf`，再构建静态站。构建时会将该文件和顶部导航的下载入口一起打包。

## 准备公开时

1. 确认 GitHub 仓库可见性与书稿、素材的公开范围，提交已审阅的内容和构建配置到默认分支。
2. 在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **Deploy from a branch**，再选择 `main` 和 `/docs`。`docs/.nojekyll` 会让 GitHub Pages 直接发布生成好的文件。 [GitHub Pages 发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
3. 用无登录窗口核对首页、全书目录、中文搜索和任一详读。项目站点预期地址为 `https://jackywjj.github.io/breeding-learning-course/`，可用地址以部署回执为准。 [项目站点地址](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

GitHub Free 支持从公开仓库使用 Pages。某些方案支持从私有仓库发布，站点仍可能公开，公开前应核对 Pages 的访问控制。 [GitHub Pages 可见性说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

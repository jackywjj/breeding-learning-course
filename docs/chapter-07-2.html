The author tutorial jointly solves fixed effects and animal random effects, using A−1A^{-1} to represent relationship-based covariance constraints.

02 · 列清数据与假设 / State data and assumptions

两头教学动物的记录为 y=[810,814]′y=[810,814]' g/day，每头一条记录，彼此无关且不近交。
Two hypothetical animals have records y=[810,814]′y=[810,814]' g/day, one per animal, and are unrelated and non-inbred.

未知固定均值记为 bb，两个加性作用记为 a1,a2a_1,a_2，模型为 yi=b+ai+eiy_i=b+a_i+e_i。
Let bb be the unknown fixed mean and a1,a2a_1,a_2 the additive effects, with model yi=b+ai+eiy_i=b+a_i+e_i.

假设遗传与残差彼此独立，各自方差均已知为 1 (g/day)2(g/day)^2，不用于代表真实猪群参数。
Assume independent genetic and residual components, each with known variance 1 (g/day)2(g/day)^2, without representing real-herd parameters.

X=[11],Z=[1001],A=I2,λ=σe2/σA2=1 X=\begin{bmatrix}1\\1\end{bmatrix},\quad Z=\begin{bmatrix}1&0\\0&1\end{bmatrix},\quad A=I_2,\quad \lambda=\sigma_e^2/\sigma_A^2=1

XX 的两个 1 让两条记录共享同一个均值，ZZ 则把各条记录连接到各自动物。
The two ones in XX give both records one shared mean, while ZZ connects each record to its animal.

04 · 不用软件也能解 / Solve without specialist software

第二、三行分别给出 â1=(810−b̂)/2\hat a_1=(810-\hat b)/2、â2=(814−b̂)/2\hat a_2=(814-\hat b)/2。
Rows two and three give â1=(810−b̂)/2\hat a_1=(810-\hat b)/2 and â2=(814−b̂)/2\hat a_2=(814-\hat b)/2.

代入第一行后得到 b̂=812\hat b=812，再回代得到 â1=−1\hat a_1=-1、â2=1\hat a_2=1 g/day。
Substitution into row one gives b̂=812\hat b=812, then back-substitution gives â1=−1\hat a_1=-1 and â2=1\hat a_2=1 g/day.

原始相对均值偏差为 −2、+2，但 EBV 为 −1、+1，展示方差结构带来的收缩。
Raw deviations from the mean are −2 and +2, while EBVs are −1 and +1, illustrating covariance-driven shrinkage.

05 · 用正则化直觉再理解 / A regularization interpretation

本例等价于最小化残差平方与遗传效应平方惩罚之和，惩罚系数由方差比决定。
This example equivalently minimizes squared residuals plus a squared genetic-effect penalty whose weight comes from the variance ratio.

Q=(810−b−a1)2+(814−b−a2)2+λ(a12+a22) Q=(810-b-a_1)^2+(814-b-a_2)^2+\lambda(a_1^2+a_2^2)

对每个未知量分别求变化率并令其为 0，会得到上面的三行方程。
Setting the rate of change with respect to each unknown to zero gives the three equations above.

若真实模型的方差比改为 λ=4\lambda=4，这个对称例子的均值仍为 812，但 EBV 变为 −2/5,+2/5-2/5,+2/5。
If the model variance ratio changes to λ=4\lambda=4, this symmetric example still has mean 812, while EBVs become −2/5,+2/5-2/5,+2/5.

这不允许为了期望排名任意选择惩罚，方差比必须来自适用模型与数据依据。
This does not permit choosing a penalty to obtain desired rankings, because the variance ratio must be justified by the model and data.

07 · 可运行校验 / Runnable verification

代码只使用标准库和小型消元，不能作为大规模稀疏生产求解器。
The code uses only the standard library and small-scale elimination and is not a large sparse production solver.

def solve(matrix, rhs):
    n = len(rhs)
    rows = [list(map(float, row)) + [float(value)]
            for row, value in zip(matrix, rhs)]
    for j in range(n):
        pivot = max(range(j, n), key=lambda i: abs(rows[i][j]))
        rows[j], rows[pivot] = rows[pivot], rows[j]
        if abs(rows[j][j]) < 1e-12:
            raise ValueError("Singular teaching system")
        scale = rows[j][j]
        rows[j] = [v / scale for v in rows[j]]
        for i in range(n):
            if i != j:
                factor = rows[i][j]
                rows[i] = [a - factor*b for a, b in zip(rows[i], rows[j])]
    return [row[-1] for row in rows]

C = [[2, 1, 1], [1, 2, 0], [1, 0, 2]]
b, a1, a2 = solve(C, [1624, 810, 814])
print(f"mean={b:.2f}; EBV1={a1:.2f}; EBV2={a2:.2f}")

基础 R 可用 solve(C, rhs) 直接解同一组方程，第一行输出与 Python 一致。
Base R uses solve(C, rhs) to solve the same system directly, and its first output line matches Python.

再用 solve(C) 取逆矩阵的右下两行两列，按前一节的残差方差和加性方差复核两头动物的 PEV、REL 与 ACC。
Then solve(C) supplies the lower-right two-by-two block of the inverse, and the residual and additive variances from the previous section give PEV, REL, and ACC for both animals.

C <- matrix(c(
  2, 1, 1,
  1, 2, 0,
  1, 0, 2
), nrow = 3, byrow = TRUE)
rhs <- c(1624, 810, 814)

solution <- solve(C, rhs)
stopifnot(isTRUE(all.equal(drop(C %*% solution), rhs)))
cat(sprintf(
  "mean=%.2f; EBV1=%.2f; EBV2=%.2f\n",
  solution[1], solution[2], solution[3]
))

residual_var <- 1
additive_var <- 1
animal_rows <- 2:3
pev_matrix <- solve(C)[animal_rows, animal_rows] * residual_var
pev <- diag(pev_matrix)
rel <- 1 - pev / additive_var
acc <- sqrt(rel)

stopifnot(isTRUE(all.equal(
  pev_matrix, matrix(c(0.75, 0.25, 0.25, 0.75), nrow = 2)
)))
for (i in seq_along(pev)) {
  cat(sprintf("animal=%d; PEV=%.2f; REL=%.2f; ACC=%.2f\n",
              i, pev[i], rel[i], acc[i]))
}
